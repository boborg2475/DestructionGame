### Load solver

- **A cohesionless joint with a real tensile bond survives the withheld one-cell relief, and that entangles gap 5 behind gap 4.** Measured while designing `AOneCellArchMustEarnItsThrust` (its header records the whole finding): `CohesionlessBond` — dry stone's μ = 0.7 with a real 0.08 MPa tensile bond — is refused the relief correctly at 1.4921 of sliding capacity, and then does **not** fail, because composite vertical action re-sections the moment and it reads **0.807**. So for a zero-cohesion joint the honest verdict needs DESIGN §7 **gap 5** as well — the deep beam's horizontal shear flow is never applied as a demand on the bed joints that must carry it — and a row asserting the outcome today could only be satisfied by closing both. That is why the acceptance table has no such row; write the gap-5 demand first, then the row.
- **The one-cell thrust check credits the whole moment vector's magnitude, torsion included.** `(1 − k)·|M|` at the call site in `SolveLoads` takes `FVector::Size()`, where only the in-plane part is what a horizontal pair can supply; a component about the seat's own normal is torsion, which DESIGN §5.3 does not model and which gravity on an axis-aligned rectangle never produces. The difference can only ever ask for *more* thrust, so it fails closed — but the day a joint carries a torsional moment, this judges it slightly harshly. Distinguishing fixture needed before either spelling can be preferred.
